Hướng Dẫn Sử Dụng Auto PR Generator

1

Dán link GitHub Pull Request

Sao chép URL của PR bạn cần tóm tắt (ví dụ: https://github.com/owner/repo/pull/123) và dán vào ô nhập liệu. Hệ thống hỗ trợ cả Pull Request của Repository Private nếu máy tính của bạn đã đăng nhập qua gh auth login.

2

Lựa chọn mô hình AI

Bạn có thể chọn Claude Sonnet 4.6 (Thinking) để có phân tích mã nguồn chi tiết và chính xác nhất, hoặc Gemini 3.8 Flash để tóm tắt cực nhanh.

3

Tự động sinh mô tả chuẩn

Nhấn nút "Tạo PR Description". AI sẽ phân tích toàn bộ commit messages, các file thay đổi, diff mã nguồn và tạo ra bản mô tả bằng tiếng Anh chuẩn theo cấu trúc:

  • ## What: Chi tiết các thay đổi logic và component.
  • ## Why: Lý do thay đổi và bài toán cần giải quyết.
  • ## How to QA?: Checklist các bước kiểm thử và cam kết release.
  • ## Any screenshots or loom video?: Vị trí đính kèm hình ảnh/video.
  • ## Types of changes: Tự động đánh dấu checkbox phù hợp (Bugfix, Feature, Performance...).
  • ## Automation tests:: Gợi ý các test cases tự động hóa hữu ích.
4

Xem trước & Sao chép

Kiểm tra bản xem trước trực quan (Rendered Preview) hoặc chỉnh sửa trực tiếp trên tab Markdown. Nhấn "Sao Chép Markdown" và dán vào phần Description của Pull Request trên GitHub!
